# سوزان

مرجع فنی کامل مخزن (API، داده، اجرا، استقرار): [`فنی.md`](فنی.md). این فایل یادداشت عملیاتی هاب و خانه است.

سوزان پنل ساخت و ادارهٔ فروشگاه اینترنتی است: از چت، سایت را سفارش می‌دهی، محتوا می‌سازی، و فروش را از یک داشبورد کاغذی-مسی می‌بینی. برند علامت خورشید و ماه مسی روی پلاک زغالی است؛ زمینهٔ پنل روشن می‌ماند.

## نشانی‌های زنده

| نقش | نشانی |
| --- | --- |
| ریشه | https://sozan-core.ir |
| پنل | https://app.sozan-core.ir |
| API | https://api.sozan-core.ir |
| فروشگاه | `https://{slug}.sozan-core.ir` بعد از ساخت |

بازدیدکننده HTTPS می‌گیرد. لبهٔ ابرآروان با سرور اصلی **HTTP** حرف می‌زند.

ورود با شماره و کد یک‌بارمصرف است. در حالت توسعه API ممکن است کد را در پاسخ برگرداند؛ در تولید باید پیامک روشن باشد.

## سه سطح محصول

**لندینگ.** ریشهٔ `sozan-core.ir` صفحهٔ معرفی است: تایپ بزرگ، علامت مسی، و مسیر ورود به پنل. `www` به همان ریشه می‌رود. پنل روی `app.sozan-core.ir` می‌ماند.

**چت فروشگاه.** مسیر اصلی ساخت سایت. حس، رنگ و امکانات را می‌پرسی؛ با «بساز» کارخانه شروع می‌شود. اسکن اینستاگرام از کپشن پیج مشخصات کالا را می‌کشد (نام، قیمت، رنگ، سایز) و همان کاتالوگ را به کارخانه می‌دهد؛ دسته یا کالای ساختگی — مثل مانتو و شلوار وقتی پیج فقط کیف است — نباید ساخته شود. تصویر ژنراتوری روی هاب ساخته نمی‌شود؛ عکس همان پست کانال روی کارت کالا می‌رود. هر دستور فروشنده در پوشهٔ `shop-workspace` همان مستأجر ثبت می‌شود (`commands.jsonl` و `instructions.md`) و فایل‌های ادیت‌شده در `shop-workspace/files` کپی می‌گردد؛ چت و بیلد همان پوشه را می‌خوانند تا دستورهایی مثل «قیمت نزن» یا «از پیجم بگذار» گم نشود. بعد از آماده شدن، پیش‌نمایش زنده با مقیاس ۷۵٪ داخل کادر بالای چت است و حالت طراحی دارد: هاور و کلیک المان را برای ادیت انتخاب می‌کند؛ دکمهٔ مرور لینک‌ها را آزاد می‌گذارد. کادر بسته می‌شود. خانه/کالاها/سبد و تازه‌کردن خود iframe را عوض می‌کنند. ادیت متن و رنگ همان لحظه در کادر دیده می‌شود؛ کارخانه راه نمی‌افتد تا دکمهٔ **بیلد** روی کادر (یا «دوباره بساز» در چت) زده شود. اگر فروشنده بگوید مدل‌ها را از پیج بگذار، همان کاتالوگ اسکن‌شده است نه ادیت TSX. سؤال یا پیشنهاد بهبود را جواب می‌دهد. سلام کوتاه جدا است. دامنهٔ شخصی از منوی کرهٔ زمین با CNAME به `{slug}.sozan-core.ir.` ست می‌شود.

**چت استودیو.** کپشن اینستاگرام، تلگرام و واتساپ را در چت می‌سازد و کمپین را ذخیره می‌کند. تصویر و ویدیوی ساخته‌شده در همان حباب دیده می‌شود و از همان‌جا به کانال ثبت‌شده فرستاده می‌شود. تصویر پیوست همان عکس پست می‌شود؛ بدون عکس فقط متن می‌ماند. سلام کوتاه کمپین نمی‌سازد. اینباکس فروش پیامک/گفتگو را نشان می‌دهد و ضمیمه ندارد.

**پنل.** فروش، موجودی، کانال‌ها، برند، تنظیمات پرداخت و پیامک، پلن تعداد سایت. تب‌بار پایین روی موبایل و دسکتاپ یکسان است. راهنمای فروشنده در بیشتر → اسناد آموزشی است.

## معماری

پنل، API، Postgres، Redis و پراکسی فروشگاه‌ها روی **هاب** هستند. گیت‌وی‌های OpenClaw و مدل محلی روی **ماشین خانه** می‌مانند.

```
بازدیدکننده --HTTPS--> ابرآروان --HTTP :8088--> nginx هاب
                              |-> پنل 127.0.0.1:3010
                              |-> API 127.0.0.1:8012
                              '-> فروشگاه 127.0.0.1:{port}

API هاب --18789--> گیت‌وی سوزان روی 94.183.65.149
پیام‌رسان‌ها روی اینترنت مستقیم هاب فیلتر می‌شوند. API اینستاگرام و تلگرام از SOCKS خانه روی `127.0.0.1:10888` (تونل معکوس به پروکسی محلی خانه) می‌روند. مدل همان تونل ۹۲۹۲ است.
```

IP عمومی هاب برای مبدأ CDN: `37.152.189.216`. IP خانه برای گیت‌وی: `94.183.65.149`.

## DNS و دامنهٔ شخصی

زون `sozan-core.ir` در ابرآروان فعال است. رکورد A ابری با `upstream_https=http` برای `@`، `www`، `app`، `api` و بعد از ساخت برای `{slug}`. ویلدکارد `*` از API ابرآروان برای این زون ساخته نشد؛ هر فروشگاه رکورد جدا می‌گیرد.

دامنهٔ مشتری: در پنل CNAME به `{slug}.sozan-core.ir.` نشان داده می‌شود. سوزان DNS رجیسترار مشتری را عوض نمی‌کند. بعد از ذخیره، lookup وضعیت را نشان می‌دهد (درست / هنوز نیامده) و دامنه با CNAME Setup ابرآروان ثبت می‌شود تا SSL لبه برای هاست سفارشی صادر شود. nginx همان Host را به پورت همان فروشگاه می‌فرستد.

کلید API ابرآروان فقط در env هاب با mode `600` است؛ در گیت و این سند نیست. کلیدی که در گفتگو آمده را در پنل ابرآروان بچرخان.

## چت و رسانه

`POST` چت فروشگاه و استودیو هم JSON `{text}` می‌پذیرد هم multipart با `text` و فایل. ذخیره زیر `chat-media/` با سقف حجم جدا برای تصویر / ویدیو / صدا. اینباکس رسانه ندارد.

## مدل و گیت‌وی

چت پنل از `LOCAL_LLM_URL` روی هاب می‌رود؛ الان `http://127.0.0.1:9292/v1` از راه تونل به **sozan-observe** روی خانه، و از آنجا به llama-swap روی `127.0.0.1:19292`. مدل چت پیش‌فرض `qwen3.8-27b` است؛ `qwen3.5-9b` روی GPU0 برای اپراتور می‌ماند. نشانی گیت‌وی عمومی در تنظیمات: `http://94.183.65.149:18789`.

واحد systemd کاربر روی خانه: `llama-swap.service` (`19292`)، `sozan-observe.service` (`9292`)، `sozan-llm-tunnel.service` (`ssh -R 127.0.0.1:9292:127.0.0.1:9292 hub`). llama-swap و observe را روی `0.0.0.0` باز نکن.

مانیتور اپراتور فقط روی خانه است: `http://127.0.0.1:9292/observe/`. پیام هر فروشنده، ریکوست هر مدل، و رویداد ساخت/اینباکس/اسکن در SQLite محلی می‌ماند. خروجی فاین‌تیون: `/observe/api/export.jsonl`. این فایل را به گیت یا هاب کپی نکن.

## کارخانهٔ سایت

درخت slim کارخانه روی هاب است: `/home/ubuntu/site-builder` (بدون `builds/` چندده‌گیگی). «بساز» اسکریپت `tools/sozan_factory_fastpath.py` را با گیت‌وی خانه (`94.183.65.149:18789`) و مدل تونل‌شده (`127.0.0.1:9292`) اجرا می‌کند. تصویر Comfy روی هاب ساخته نمی‌شود (`--skip-images`). اگر اسکن کانال عکس داشته باشد همان فایل به `public/products` می‌رود؛ اگر نباشد سوزان قبل از بیلد عکس کالا و هیرو را از observe (`/observe/api/image`) می‌سازد و به‌عنوان `sourceImage`/`sourceHero` به کارخانه می‌دهد. کارخانه کاتالوگ اسکن‌شده را با `--catalog` می‌گیرد و ردیف‌های قالب مد (مانتو/شلوار) را نمی‌گذارد. نوع سایت از دستهٔ کاتالوگ می‌آید نه `fashion` ثابت. npm فروشگاه از `registry.npmjs.org` از راه تونل HTTP خانه (`127.0.0.1:10889`) نصب می‌شود؛ آینهٔ runflare روی هاب `402` می‌دهد. کانتینر فروشگاه به `127.0.0.1` بایند می‌شود.

اگر اسکریپت نباشد، چت همان خطای «اسکریپت کارخانه پیدا نشد» را نشان می‌دهد.

## استودیو

چت استودیو همان مدل تونل‌شده را می‌زند و کمپین را در Postgres ذخیره می‌کند. ساخت ویدیو به `ffmpeg` روی هاب نیاز دارد؛ اگر ffmpeg نباشد کپشن ذخیره می‌شود و علت ساخته‌نشدن ویدیو در همان جواب چت می‌آید.

## اینستاگرام و تلگرام و واتساپ

در ثبت‌نام فقط یک کانال (اینستاگرام یا تلگرام) و فقط برای خواندن ثبت می‌شود: عکس و دسته‌بندی همان صفحه برای ساخت سایت می‌آید. ورود پیام و ارسال پست از بیشتر → کانال‌هاست. اسکن صفحهٔ عمومی (بدون توکن) کالا را به فروش می‌آورد. اتصال تلگرام و واتساپ با توکن است. اینستاگرام از ورود رسمی Sendbox می‌آید (`SENDBOX_API_KEY` / `SENDBOX_OAUTH_URL`؛ وب‌هوک `POST /channels/sendbox/webhook` و بازگشت `GET /channels/sendbox/callback`). فروشنده در کانال‌ها «ورود با اینستاگرام» می‌زند. یونى‌پایل فقط اگر Sendbox خاموش باشد همان دکمه را می‌گیرد. توکن دستی هنوز برای اپراتور کار می‌کند.

صندوق ورودی: تلگرام با `getUpdates` خوانده می‌شود و پاسخ اپراتور با `sendMessage` به همان `chat_id` می‌رود. اینستاگرام دایرکت از وب‌هوک Sendbox می‌آید (`POST /channels/sendbox/webhook`). پاسخ صندوق با `send_message` همان حساب Sendbox است. یونى‌پایل فقط اگر Sendbox خاموش باشد همان مسیر را می‌گیرد. پیام بات تلگرام روی پلن رایگان هم کار می‌کند. پاسخ فقط وقتی در صندوق ثبت می‌شود که ارسال به کانال موفق باشد.

پست استودیو با صندوق یکی نیست:

- **تلگرام:** آپلود فایل با `sendPhoto` / `sendVideo` به `postTarget` (کانال یا گروهی که بات ادمین آن است). نشانی عمومی لازم نیست.
- **اینستاگرام:** Content Publishing؛ `image_url` / `video_url` باید HTTPS عمومی باشد (`/public-media/{token}` با امضای کوتاه‌عمر). ریل تا `status_code=FINISHED` صبر می‌کند، بعد `media_publish`. مقصد همان صفحهٔ وصل‌شده است.
- **واتساپ:** فید عمومی ندارد. آپلود رسانه به Cloud API و پیام به شمارهٔ `postTarget`. خارج از پنجرهٔ ۲۴ساعته معمولاً قالب تأییدشده لازم است.

## استقرار هاب

کد در `/home/ubuntu/sozan-core`. سرویس‌ها: `sozan-api.service`، `sozan-panel.service`، `deploy/docker-compose.yml`. سایت nginx: `sozan-core`. همگام‌سازی با rsync از ورک‌استیشن؛ `.env` هاب و `deploy/shop-upstreams.map` کپی نمی‌شود. `NEXT_PUBLIC_API_URL` هنگام `next build` روی `https://api.sozan-core.ir` پخته می‌شود.

## محدودیت‌ها

- لیبل DNS فارسی نمی‌شود.
- origin بین لبه و هاب HTTP است؛ TLS مال لبه است.
- گیت‌وی و وزن مدل روی خانه می‌مانند.
- تونل ۹۲۹۲ اگر قطع شود چت مدل خطا می‌دهد تا تونل برگردد.
- OTP در حالت mock کد را در JSON می‌دهد؛ برای پیامک واقعی mock را خاموش کن.
